# 一、AMP 训练健康度判断流程图

目标：
快速判断训练是否健康，并定位问题类别。

---

# 总体原则

AMP 训练包含三条子系统：

1. PPO 学习是否稳定
2. 判别器是否健康
3. 奖励设计是否合理

判断必须按顺序进行。

---

# 流程图（文字结构版）

```
开始
  ↓
Step 1: Reward 是否长期上升？
  ├─ 否 → 去 Step A（奖励问题）
  └─ 是
        ↓
Step 2: Episode Length 是否稳定或增加？
  ├─ 否 → 去 Step B（稳定性问题）
  └─ 是
        ↓
Step 3: Value Loss 是否稳定？
  ├─ 否 → 去 Step C（PPO不稳定）
  └─ 是
        ↓
Step 4: AMP 判别器是否正常工作？
  ├─ 否 → 去 Step D（对抗训练异常）
  └─ 是
        ↓
Step 5: Action Noise 是否逐渐下降？
  ├─ 否 → 去 Step E（未收敛）
  └─ 是
        ↓
训练健康
```

---

# Step A：Reward 不增长

可能原因：

1. 奖励权重设计不合理
2. 主奖励太小，被惩罚淹没
3. 奖励过稀疏
4. 动作空间过大

解决方向：

* 调整奖励权重比例
* 增强主任务信号
* 降低过强惩罚项

---

# Step B：Episode Length 不稳定

表现：

* 频繁 early termination
* 长度波动剧烈

可能原因：

* 姿态不稳定
* 动作过大
* 奖励过于激进

优先检查：

* base height
* torque penalty
* action rate

---

# Step C：Value Loss 发散

表现：

* critic loss 持续上升
* 大幅震荡

原因：

* 学习率过大
* 奖励尺度过大
* 回报方差太大

解决：

* 降低 critic lr
* 归一化 reward
* 使用 reward scaling

---

# Step D：判别器异常

异常表现：

1. expert 和 policy 输出都接近 0
   → 判别器崩溃

2. expert ≈ 1，policy ≈ -1 长期不变
   → 策略无法接近专家

可能原因：

* 判别器过强
* AMP reward 权重过小
* 专家数据不匹配

解决：

* 降低判别器 lr
* 增加 AMP reward weight
* 检查 motion 数据分布

---

# Step E：Action Noise 不下降

表现：

* 长期高噪声

说明：

* 策略未收敛
* reward 不稳定

可能原因：

* 多目标冲突
* 奖励震荡

---

# 二、奖励权重调参系统方法

这是最重要部分。

目标：
避免“凭感觉调参”。

---

# 1. 核心原则

不要直接调权重数值。

必须按以下步骤：

1. 先归一化奖励
2. 再调整比例
3. 每次只改一个权重
4. 观察趋势 ≥ N iterations

---

# 2. 奖励结构标准形式

奖励通常为：

[
R = w_1 R_{task} + w_2 R_{smooth} + w_3 R_{energy} + w_4 R_{amp}
]

其中：

* R_task → 任务奖励
* R_smooth → 平滑惩罚
* R_energy → 扭矩惩罚
* R_amp → 模仿奖励

---

# 3. 第一步：尺度统一（极重要）

目标：

让所有子奖励处于相近数量级。

方法：

统计每个 reward 项的平均绝对值：

[
\bar{R_i}
]

调整权重使：

[
w_i \cdot \bar{R_i} \approx 1
]

目的：

防止某一项主导训练。

---

# 4. 第二步：确定主任务优先级

问自己：

“这个机器人最重要目标是什么？”

例如：

* 速度跟踪
* 稳定站立
* 模仿动作

主任务奖励必须占主导地位。

一般建议：

主任务项贡献 40%–70%

---

# 5. 第三步：分阶段调参法

阶段一：只训练基础稳定性

* 去掉 AMP
* 去掉复杂奖励
* 只保留 tracking + 基础稳定

目标：

先学会站稳 + 跟踪

---

阶段二：加入 AMP

* 缓慢增加 AMP 权重
* 观察 policy pred 是否上升

原则：

不要一开始就给很大 AMP 权重。

---

阶段三：增加惩罚项

逐步加入：

* torque penalty
* smoothness
* action rate

防止策略过早受限。

---

# 6. 调参判断矩阵

| 现象    | 调整方向              |
| ----- | ----------------- |
| 抖动严重  | ↑ smooth penalty  |
| 扭矩过大  | ↑ torque penalty  |
| 不跟踪速度 | ↑ tracking reward |
| 不模仿   | ↑ AMP weight      |
| 不稳定   | ↑ 姿态奖励            |
| 奖励震荡  | ↓ 主奖励幅度           |

---

# 7. 多目标冲突处理

常见冲突：

* AMP 要求自然
* Tracking 要求精准

解决方法：

使用 curriculum：

[
w_{amp}(t) ↑
]

随时间逐渐增加 AMP 权重。

---

# 8. 工程级调参流程

标准流程：

1. 固定 seed
2. 跑 baseline
3. 只改一个权重
4. 记录 reward 曲线
5. 对比 3 次实验
6. 选择趋势更优者

---

# 9. 绝对禁止做的事情

* 同时改多个权重
* 根据单次 iteration 调参
* 在训练初期频繁调参
* 不保存日志就调参

---

# 10. 成熟训练的标志

1. Reward 平滑
2. Episode length 稳定
3. 判别器稳定
4. Noise 下降
5. 动作自然

---

# 最重要总结

AMP 训练本质是三方博弈：

* 策略
* 判别器
* 奖励设计

健康训练必须：

* PPO 稳定
* 判别器不过强不过弱
* 奖励比例合理
